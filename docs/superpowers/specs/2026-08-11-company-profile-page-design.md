# 회사 소개서 페이지 — 설계

## 배경

기존 "회사 소개서" 버튼(`/company_profile.pdf`)은 홈페이지 내용과 안 맞아 삭제된 상태다. 새 회사 소개서를 만들어 다시 연결한다. 지금까지 만든 `HR One`/`HR Intelligence Suite` 브로슈어와 같은 패턴 — 사이트 브랜드에 맞춘 독립 HTML 페이지, 새 탭에서 열림 — 을 따른다.

## 형식

- `public/company-profile.html` — 사이트 도메인(ellev.co.kr) 아래 독립 정적 HTML 페이지, 외부 의존성 최소화(가능하면 이미지/폰트 CDN 없이 자체 완결)
- 히어로 섹션(또는 그에 준하는 위치)의 버튼에서 새 탭으로 연결 (버튼 문구는 추후 지정)
- 디자인(색상·타이포·레이아웃 톤)은 **사용자가 별도로 작업 폴더에 넣어줄 디자인 자료를 기준으로 적용** — 이 스펙은 콘텐츠 구성과 데이터 출처만 정의하고, 시각 디자인은 그 자료 확인 후 별도로 확정한다.

## 콘텐츠 구성 (8개 섹션, 모두 홈페이지 기존 콘텐츠에서 재구성)

1. **표지** — 워드마크(엘레브앤컴퍼니) + "회사소개서" + 태그라인("조직과 사람, 그리고 변화를 잇는 통합 AI HR 솔루션 파트너")
   - 출처: `src/App.tsx` Hero 섹션 태그라인

2. **인사말** — 대표 전인식 인사말 축약본
   - 출처: `src/App.tsx` `GreetingSection` (line 476-506) — 전문을 다 넣지 않고 핵심 문단만 발췌

3. **한눈에 보는 엘레브앤컴퍼니** — 통계 4개
   - 출처: `src/App.tsx` `StatsClientsSection` (line 687-721) — 25년+ 컨설팅 경력, 150여 건 누적 프로젝트, 80%+ 재계약률, 50여 건 강의 실적

4. **핵심 가치** — 사람(People) · 혁신(Innovation) · 전문성(Quality) 3개
   - 출처: `src/data.ts` `coreValues` 배열

5. **사업 영역** — 2개 사업모델 + 하위 서비스
   - 출처: `src/data.ts` `businessModels`(2개: 조직·인사 컨설팅, AI HR One Intelligence Suite) + `detailedServices`(4개 탭의 items) — 조직·인사 컨설팅 산하에 조직진단/조직·인사컨설팅/변화관리 묶고, AI HR One Intelligence Suite 산하에 AI 기반 E-HR 시스템 묶음 (지난 작업에서 확인된 그룹핑)

6. **대표 프로필** — 전인식 대표 경력 요약
   - 출처: `src/App.tsx` `ProfileSection` (line 759-841) — 총 경력 개요, 프로젝트 트랙 레코드, 심화 전문 영역 3개, 지식 자본 항목을 요약해서 축약

7. **주요 고객사** — 공공/민간 하이라이트
   - 출처: `src/data.ts` `publicClients`(49건) / `privateClients`(28건) — 전체 나열이 아닌, 대표성 있는 일부만 선별해 "외 다수" 표기 (선별 기준은 구현 시 첫 N개 또는 잘 알려진 기관 우선으로 결정)

8. **Contact** — 이메일 문의 안내만
   - 주소·전화번호 등 공식 정보는 아직 없음 — 사용자가 나중에 채울 수 있도록 플레이스홀더 없이 비워두고, 홈페이지 상담 문의 폼(`ellev.co.kr/#contact`)으로 유도하는 방식만 넣는다
   - 이메일 주소는 별도로 확인 필요 (기존 AI HR 브로슈어의 `aisystemgaebal@gmail.com`은 별개 제품 문의용이라 회사 소개서에 그대로 쓸지는 미정 — 구현 전 확인)

## 범위 밖 (Out of scope)

- 실제 시각 디자인(색상, 폰트, 레이아웃 CSS) — 사용자가 제공할 디자인 자료 확인 후 별도 작업
- 회사 주소·전화번호·사업자등록번호 — 정보 없음, 이번 범위에 포함하지 않음
- 케이스 스터디(Case Studies) 섹션 상세 재현 — 8개 항목 구성에 포함하지 않음(주요 고객사 섹션으로 대체)

- 홈페이지 어디에 새 버튼을 연결할지 (Hero 섹션에 "AI-Powered HR Platform" 버튼 옆? 별도 위치?)
