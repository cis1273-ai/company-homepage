# 상담문의 ellev1273@gmail.com 수신 설정 가이드

홈페이지 하단 상담문의를 작성하여 제출했을 때, 문의 내용이 **`ellev1273@gmail.com`** 으로 즉시 자동 발송되도록 하는 구글 스프레드시트 Apps Script 설정 안내입니다.

---

## 1. 구글 스프레드시트 열기

1. 연동 중인 **구글 스프레드시트**를 브라우저에서 엽니다.
2. 상단 메뉴에서 **확장 프로그램** → **Apps Script**를 클릭합니다.

---

## 2. 코드 교체

1. Apps Script 편집기 왼쪽의 `코드.gs` (또는 `Code.gs`) 파일을 엽니다.
2. 기존에 작성되어 있던 모든 내용을 지우고, [`docs/google-apps-script-code.gs`](google-apps-script-code.gs)의 전체 코드를 복사하여 붙여넣습니다.
3. 코드 상단 14번째 줄에 관리자 이메일이 올바르게 지정되어 있는지 확인합니다:
   ```javascript
   var ADMIN_EMAIL = 'ellev1273@gmail.com';
   ```
4. 상단 디스켓 아이콘(💾 **저장**, `Ctrl + S`)을 눌러 저장합니다.

---

## 3. 웹 앱 재배포 (★매우 중요)

코드를 저장한 후 반드시 **"배포 관리"에서 새 버전으로 업데이트**해야 새 코드가 적용됩니다. (새 배포를 누르면 URL이 바뀌므로 배포 관리를 이용해야 합니다.)

1. 오른쪽 상단 파란색 **[배포]** 버튼 옆의 드롭다운을 눌러 **[배포 관리]** 를 클릭합니다.
2. 활성 배포 목록에서 오른쪽의 연필 모양 **[✏️ 수정]** 아이콘을 클릭합니다.
3. **버전** 드롭다운을 클릭하고 **[새 버전]** 을 선택합니다.
4. 설명에 `관리자 메일(ellev1273@gmail.com) 알림 기능 추가` 등을 입력합니다.
5. 하단의 **[배포]** 버튼을 누릅니다.
6. 완료 창이 뜨면 **[완료]** 를 누릅니다.

> **참고**: 권한 승인 창(이메일 발송 권한 등)이 나타나면 `고급` → `...으로 이동(안전하지 않음)`을 클릭한 뒤 `허용`을 눌러주시면 됩니다.

---

## 4. 작동 테스트

1. 웹사이트 하단의 **[상담 문의하기]** 버튼을 클릭하여 테스트 문의를 작성하고 제출합니다.
2. **`ellev1273@gmail.com`** 받은편지함(스팸함 포함)에 다음과 같은 알림 메일이 도착하는지 확인합니다:
   - **제목**: `[신규 상담문의 접수] 회사명 / 홍길동님`
   - **본문**: 접수 일시, 성함, 회사명, 이메일, 연락처, 상세 문의 내용 및 관리자 페이지 링크
3. 동시에 테스트로 입력한 신청자 이메일에도 접수 확인 안내 메일이 도착합니다.
4. 구글 스프레드시트와 관리자 페이지(`/#admin`)에도 동일하게 행이 기록되고 정상 관리됩니다.
