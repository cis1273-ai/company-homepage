— 01 / Why

공공기관·기업의 인사담당자가 신뢰하는 3가지 이유.

그럴듯한 답변을 지어내는 AI가 아니라, 국가표준과 25년의 현장 노하우 위에서 검증되는 AI. HR AI Lab의 모든 솔루션은 이 세 가지 원칙 위에 있습니다.

i.

NCS · 국가표준 기반

공공데이터포털 NCS Open API 실시간 연동. 24개 대분류부터 세분류까지 공식 능력단위·코드로만 매칭하며, 규칙 엔진으로 결과를 산출해 "AI가 지어낸 지표"의 리스크를 원천 차단합니다.

ii.

25년 컨설팅 노하우 내장

공공 108건 · 민간 42건, 150여 건 프로젝트에서 축적한 실무 판단이 규칙과 프롬프트에 녹아있습니다. SMARTI·STAR·BSC·MBO 같은 실전 방법론이 그대로 시스템에 구현되어 있습니다.

iii.

담당자 업무시간 대폭 절감

직무기술서 작성 -80%, 면접 가이드 설계 -70%, 규정 안내 응대 24/7 자동. 설치·서버·로그인이 필요 없는 웹 기반으로 즉시 도입해 즉시 효과를 확인합니다.

채용 평가 & 면접 가이드 자동생성

"AI에게 이력서를 그대로 보여주지 않고도, AI 수준의 면접 가이드를 만든다."

Problem 채용 담당자가 지원자 이력서를 외부 AI에 그대로 붙여넣어 개인정보가 유출되는 위험, 면접관마다 다른 평가 기준, 공공기관 블라인드 채용의 익명성 관리 부담.

Core Features

  • i.100% 클라이언트사이드 처리 — 서버·DB가 없는 순수 정적 웹앱. 이력서 원문이 브라우저 밖으로 나가는 경로 자체가 없음
  • ii.AI 분석 전 자동 개인정보 마스킹 — 이름·연락처·이메일·생년월일·학교명을 정규식으로 자동 치환 후에만 분석에 전달
  • iii.사람이 최종 검수 — 마스킹 전/후를 나란히 비교하고 담당자가 "검수 완료"를 눌러야 다음 단계로 진행
  • iv.STAR 기반 구조화 질문 + 자동 루브릭 — 역량별 메인/꼬리질문과 상·중·하 평가 기준표를 함께 자동 생성
  • v.용도별 3종 모드 — 단일 심층분석 / JD 매칭 / 다수 지원자 비교평가(NCS 블라인드 특화)

NCS JD Studio

직무기술서 자동생성 플랫폼

"NCS 선택만으로 초안 자동생성. 5분 안에 완성도 높은 직무기술서를 완성합니다."

Problem 직무기술서를 처음부터 작성하는 데 수일 소요. 담당자 편차로 인한 문서 품질 불균형. 공식 인쇄 레이아웃까지 별도 정리 필요.

Core Features

  • i.4단계 자동 생성 워크플로우 — NCS 24개 대분류 → 중분류 → 세분류 3단계 드릴다운으로 즉시 초안 생성
  • ii.35개 직무 전문가 큐레이션 콘텐츠 내장 — 표준 초안에 실무 판단이 반영된 문구가 기본값으로 포함
  • iii.자동 생성 + 완전 자유 편집 — AI 초안을 회사·직급에 맞게 100% 수정 가능. 초안 다시 생성으로 여러 버전 선택
  • iv.공문서 수준의 최종 산출물 — 공식 인쇄 레이아웃 + 페이지 나눔 최적화 + PDF/인쇄 원클릭
  • v.NCS 자동 반영 — 법·제도 변경 시에도 NCS만 업데이트하면 전체 문서에 자동 반영

AI KPI-PI 설계 시스템

전략과제·개인성과지표 자동설계

"전략과제와 개인 업무분장을 입력하면 SMARTI 기준으로 검증된 KPI/PI를 원스톱으로 산출합니다."

Problem 팀장급 전략과제와 개인 업무분장이 같은 방식으로 다뤄지며 개인성과 지표가 반복업무 나열에 그침. SMARTI 원칙 검증이 담당자 감각에 의존.

Core Features

  • i.전략과제 KPI · 개인 PI 완전 분리 트랙 — 서로 다른 화면·다른 AI 규칙. 개인PI는 반복업무도 품질·정확도·신속성 등 결과지향 지표로 전환
  • ii.7단계 자동 설계 파이프라인 — 입력 → 전략 분석 → 성과논리 설계 → KPI 후보 → 검증 → 최종 선정 → 다운로드
  • iii.SMARTI 기준 자동 검증 — Specific·Measurable·Achievable·Relevant·Time-bound·Impact 원칙에 근거를 함께 제시
  • iv.일괄 분석 — 여러 전략과제, 여러 명의 업무분장이 섞여 있어도 AI가 자동 분리 후 파이프라인 실행
  • v.다양한 문서 지원 — PDF·Excel·Word·HWPX 자동 텍스트 추출. 구형 HWP는 변환 안내로 사전 차단

Job-to-Learning Auto Matcher

"직무기술서 한 장으로, 필요한 교육과정까지 자동으로 잇습니다."

Problem 부서마다 PDF·HWP·엑셀로 제각각인 직무기술서. NCS 코드와 재직자 직무교육을 이어주는 공공 API 부재. 매칭 기준이 담당자 개인 노하우에 머물러 인수인계마다 흔들림.

Core Features

  • i.PDF · HWP · HWPX · XLSX 한 화면에서 처리 — 국내 공공기관 문서 표준인 한글 파일을 신·구버전 모두 지원
  • ii.다중 직무 자동 분리 — "보직자 직무기술서(7개).pdf"처럼 파일 하나에 여러 직무가 섞여 있어도 자동 분리

  • iv.AI 실무 교육과정 추천 — 매칭된 능력단위에 해당하는 재직자 직무교육을 AI가 추천
  • v.로그인·서버 불필요 — 담당자 PC의 브라우저만으로 즉시 사용, 문서가 외부로 나가지 않음
